# Kaizen

把 YouTube 或 B 站视频当成一本书来读：双语字幕、划线笔记、生词本，再按知识块拆开。

一句话：**看视频，也是改善。**

名字取自日语「改善」（念作 kai-zen）。改是看见自己的不足，就动手改；善是改完之后，往更好的方向去。这个词本来是工厂和公司里的说法：不指望一次巨大的颠覆，而是每个人每天在手边的事上改一点，攒下来就是质的变化。看视频也一样——一句一句划、一块一块拆，比一次看完十小时更有用。

许可证：[MIT](LICENSE)。自己申请 DeepSeek 和 Supadata 的 Key，数据只存在你这台电脑。

仓库目录仍叫 `videobricks`。GitHub 是 [Kaizen](https://github.com/CharlieLam2025/Kaizen)。对外名字也是 Kaizen。

## 你能做什么

- **阅读器**：原文 / 双语 / 译文。像微信读书一样在字幕上划线、写笔记、查词、存进生词本。侧栏可直接改播放倍速（0.5×–2×），立刻作用到视频。划一段字幕点「跟读」，会循环这一段、自动降速，听完空一拍再开口。界面可切简体、繁体、英文，以及日语、韩语、西语、法语、德语、葡语、俄语、越南语、印尼语、泰语、阿拉伯语；AI 拆解和字幕译文跟着界面语言走。
- **生词**：单独一栏，就是牌组。存进去的词会按间隔再见到（忘了 / 想起来了 / 太简单），像 Anki。顶栏设四级 / 六级 / 雅思 / 托福后，打开视频会先筛一份可能生词库。一词可记下多个视频出处，点出处跳回那一支。也可导出 TSV 给 Anki 软件。
- **拆页**：色块时间轴、按知识块类型换架子拆解（概念用 SEE-I + 属加种差，案例用类比编码 + CER，故事用冰山，做法用任务分析 + 库伯，问答用 Toulmin；默认 DeepSeek V4 Pro）。拆解回答「这块是什么」，费曼回答「你会了没有」：闭卷自己讲，AI 只指出缺口并给 SOLO 定级，不代写。某一块可单曲循环；阅读里也可以循环一句或划过的几句。
- **书签**：标题下有一条跟着播放走的书签轨。点「夹在这里」、划词条「夹书签」，或按 `B`，会在这一秒夹一枚。走到附近会弹出书签卡。标记可以是丝带、猫、狗、鸟、圆、印，也可以上传家里猫狗的照片。照片和书签都只存在本机。
- **跟随播放**：阅读器默认跟着视频滚；点时间戳或输入 `12:30` 可跳转。点书签轨也能跳到那一秒。
- **问视频**：问整支、问某一块、或划一句再问。答案带可点击时间戳。
- **导出卡片**：金句、生词、笔记都能做成卡。金句底下可以写下你的理解。点「导出海报」在侧栏里换样子、改理解、下 PNG / SVG，不用另开一页。样子有暖报、朱墨、夜读、书页、批注、素笺、纸页、黑板、对照；卡片高度跟着文字长。按 `R` 收下正在说的原话；要的话再抽最多 3 句。
- **复习**：金句、划线做成的卡在「复习」。生词在「生词」里背。
- **视频进度条**：书签钉在 YouTube / B 站自己的进度条上。播放头可以换成丝带、猫狗或你上传的照片；夹过的点可点跳转；金色竖线是上次看到的位置。知识块拆出来后，条上方会有一条细色带。右下有 K / R / A / N / B，不必记快捷键。
- **知识库**：库里按视频看每支的知识块和金句，按概念看同一件事在不同视频里怎么讲，再跳回那一秒。
- **笔记页**：本视频的划线、笔记、金句。
- **备份**：设置里可导出 / 导入全部本机数据（笔记、生词、书签、复习卡、知识库和 Key）。换电脑或重装前先导出。

## 安装

1. `chrome://extensions` 打开开发者模式，加载本文件夹。
2. 点工具栏图标。**第一次会进入全屏设置**，按页面说明申请并填写两个 Key。
3. 看完小教程（可跳过，顶栏「教程」可重看）。
4. 打开有字幕的 YouTube 或 B 站视频，阅读器会自动铺开。

给朋友：在本目录运行 `node scripts/pack.mjs`（Windows 也可以 `powershell -File scripts/pack.ps1`），把 `dist/kaizen.zip` 发给他。他解压后按上面第 1 步加载**解压后的文件夹**（不要加载 zip 本身），再自己申请两个 Key。

开源或上架前请先看 [PRIVACY.md](PRIVACY.md)。Chrome 商店需要一份可公开打开的隐私页网址；把这个文件放到 GitHub 仓库里就能当链接用。商店审核期间建议先选 **不公开（Unlisted）**，用链接给朋友装，通过后再公开。

## 申请 Key

两个都要填。Key 只存在本机。

### DeepSeek（拆解、翻译、查词、提问）

1. 打开 [API Keys 页面](https://platform.deepseek.com/api_keys)
2. 点 Create new API key，立刻复制
3. 文档：[api-docs.deepseek.com](https://api-docs.deepseek.com/)

### Supadata（字幕）

字幕**只走 Supadata**，不再先试 YouTube 直连。

1. 打开 [注册页](https://dash.supadata.ai/auth/sign-up)，走完引导即可拿到 Key
2. 控制台：[dash.supadata.ai](https://dash.supadata.ai/)
3. 定价：[supadata.ai/pricing](https://supadata.ai/pricing)

## 项目结构

| 文件 | 职责 |
| --- | --- |
| `site.js` | YouTube / B 站地址和 B 站字幕 |
| `panel.html/css/js` | 阅读器、引导、拆页、提问、笔记 |
| `background.js` | Supadata 字幕 + DeepSeek（拆块、拆解、词典、学习包、费曼对照、翻译、问答、金句） |
| `content.js` | 只负责跳转播放和读取进度 |

扩展重载后请再点一次工具栏图标。已打开的 YouTube 页一般不用刷新；改过 `content.js` 或 `background.js` 时，YouTube 页也要刷新。
