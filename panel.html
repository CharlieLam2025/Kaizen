Kaizen · 改善

精进自己

改，看见不够，就动手改。善，改完之后，往更好去。

两个字合在一起，叫持续精进：今天比昨天清楚一点，明天再清楚一点。

DeepSeek 用来拆解和查词。字幕优先用视频自己的；YouTube 没有原生字幕时再填 Supadata。

1

DeepSeek · 拆解和查词

  1. 打开 API Keys 页面，没有账号会先让你注册。
  2. 点 Create new API key，名字填「Kaizen」即可。
  3. 立刻复制完整 Key（一般只显示一次）。
2

Supadata · 字幕（选填）

YouTube / B 站自己有字幕时可以不填。没有原生字幕，再用它补。

  1. 打开 Supadata 注册页，走完新手引导。
  2. 引导里会自动生成 Key，之后可在 控制台 查找。
3

DeepSeek 用哪个

不确定就用默认，之后随时能改。Flash 快、便宜；Pro 更稳，适合拆解。

英语大概到哪

用来从字幕里筛你可能还不熟的词。设了之后，打开视频会先给一份生词库，可以先过一遍再看。不是官方考纲，先不设也可以。

Key 只存在这台电脑的浏览器里。DeepSeek 说明：api-docs.deepseek.com · Supadata 定价：supadata.ai/pricing

作者的话

Kaizen 的意思是改善。改是看见自己的不足，就动手改。善是改完之后，往更好的方向去。

念作 kai-zen。这个词本来是工厂和公司里的说法：不指望一次巨大的颠覆，而是每个人每天在手边的事上改一点，攒下来就是质的变化。

我们看了太多内容，更多是在囤积，很少真正内化成自己的东西。

做这个插件，是希望自己能打破语言的墙，也把一些深的、偏长的内容，拆成更容易懂的短块。

希望大家不断地精进自己、改善自己。这个工具有什么好的建议，可以留言，也可以微信找我。
